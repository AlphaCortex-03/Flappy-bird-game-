FLAPPY BIRD - PYTHON (Pygame)
=============================

How to run
----------
1. Install Python 3.8 or newer.
2. Install pygame:
       pip install pygame
3. Run the game from inside this folder:
       python main.py

Controls
--------
SPACE / UP ARROW / Mouse Click : Flap
P                              : Pause / Resume
R                              : Restart after Game Over

Notes
-----
- Your best score is saved in best_score.txt (created automatically).
- No images or sounds are needed; everything is drawn with code.
